# Clear Growth Group brand assets

Source: Figma file "ClearGrowth (Copy)", page "Final" (frames `LogoType` 2001:411 and `Logo` 2001:412).

## Files

| File | Use |
|---|---|
| `clear-growth-logotype-aqua.svg` / `@4x.png` | Original logotype color (#99D8DE), for dark backgrounds |
| `clear-growth-logotype-dark.svg` / `@4x.png` | Same logotype in Deep Ink (#082026), for light backgrounds |
| `clear-growth-logotype-white.svg` / `@4x.png` | Same logotype in white, for coral or photo backgrounds |
| `clear-growth-logo.svg` / `@4x.png` | The "C" mark (teal + teal-to-blue gradient), transparent background |

The PNGs are 4x and transparent. Use the SVGs for print (poster, worksheet) whenever possible.

## Colors (exact values from the Figma file)

| Name | Hex | Where it appears |
|---|---|---|
| Deep Ink | `#082026` | Dark slide backgrounds, start of the dark gradient |
| Deep Teal | `#004A4A` | End of the dark gradient, secondary dark |
| Logo Teal | `#0A5657` | Solid parts of the logo mark |
| Logo Gradient | `#055E5F` → `#3B759B` | Gradient parts of the logo mark (top to bottom) |
| Aqua | `#99D8DE` | Logotype |
| Coral | `#FF5938` | Accent slides ("How I drive growth", "Let's chat") |
| Growth Green | `#5CC47C` | Highlighted words in case-study headlines |
| Mist | `#F4F5F8` | Light slide backgrounds |

Dark background gradient: `#082026` → `#004A4A`.

## Type

- Headlines: **Syne Bold**
- Body: **Montserrat** (Medium for body text, Bold for emphasis)
